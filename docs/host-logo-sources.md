# Host tab artwork

The connection tabs use inline SVGs with the site's muted ivory and orange
palette. Decorative icons are hidden from assistive technology; the adjacent
host names remain the accessible tab labels.

- **General:** an original simple Gossip ghost.
- **Grok Bot:** the circular, two-eyed mark from the official
  [Grok Bot introduction](https://x.ai/news/introducing-grok-bot), with its
  original paths retained and the fills adapted to the site palette.
- **Hermes:** a hand-drawn vector rendition of the caducée (☤) used in the
  [official Hermes Agent favicon](https://github.com/NousResearch/hermes-agent/blob/main/website/static/img/favicon.svg).
  Paths replace the source's text glyph so the icon does not depend on a system font.
- **OpenClaw:** the mascot geometry from the
  [official favicon](https://openclaw.ai/favicon.svg), flattened to monochrome
  with the tiny eye highlights omitted for legibility at 22 pixels.

Sources checked on 2026-09-13. The icons identify the setup targets; they do not
imply endorsement or verified host support.
